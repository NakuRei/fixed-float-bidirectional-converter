# Fixed-Float Bidirectional Converter

[English](README.md) / [日本語](README.ja.md)

固定小数点数と浮動小数点数を相互に変換するWebアプリ。

公開先: https://nakurei.github.io/fixed-float-bidirectional-converter/

## 機能

固定小数点数の整数ビット数と小数ビット数を指定し、2進数あるいは16進数表記を浮動小数点数に変換できます。ビットパターンの入力には`0b`/`0x`の接頭辞をつけていても変換できます。区切り文字は使えません。

逆に、浮動小数点数を任意のビット長の固定小数点数に変換することもできます。浮動小数点数の入力は`1.25e-1`のような指数表記も使えます。

符号付きの固定小数点数は2の補数表記として扱います。また、符号ビットは整数ビットに含めて数えます。

固定小数点数を浮動小数点数に変換するときの丸め方は偶数丸めです。浮動小数点数を固定小数点数に変換するときの丸め方は、下記から選べます。

- 最近接（偶数丸め / 0から遠い方 / +∞方向）
- 0方向（切り捨て）
- −∞方向（floor）
- +∞方向（ceiling）
- 正確な値のみ（丸めが必要な値はエラー）

また、値が固定小数点数で表せる範囲を超えたときの扱いは、下記から選べます。

- エラー（Error）
- 飽和（Saturate）
- 折り返し（Wrap）

なお、入力した形式は変換されず、入力した文字列が`original`としてそのまま表示されます。

## 使い方

1. 任意の整数ビット数と小数ビット数を設定する
1. トグルで符号付きにするか選ぶ
1. 入力形式を選び、値を入力する
1. 変換結果が表示される

たとえば、符号付きQ4.4の場合は下記のように変換されます。

| 入力 | 16進数 | 2進数 | 10進数 |
| --- | --- | --- | --- |
| `11001101`（2進数） | `CD` | `11001101` | `-3.1875` |

## 開発

Node.js 24が必要です。

```sh
npm ci
npm run dev      # 開発サーバーを起動
npm test         # テストを実行
npm run lint     # ESLint を実行
npm run verify   # lint・テスト・ビルドをまとめて実行
```
